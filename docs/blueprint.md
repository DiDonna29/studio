# **App Name**: Amor ❤️

## Core Features:

- Interactive Game Start: Present a memory game to engage the user before the proposal.
- Seamless Transition: Transition smoothly from the memory game to the proposal question.
- Personalized Proposal: Display the proposal question with the girl's name.
- Acceptance Celebration: Show a celebratory message, dynamic photo gallery and animations upon acceptance.
- Persistence Mechanism: Implement a persistence strategy, subtly enlarging the 'Yes' button while maintaining or shrinking the 'No' button upon each 'No' press, making it harder to avoid the 'Yes' option. Force a transition to 'Yes' after a number of attempts
- Language and Theme Options: Implement dual language support (Spanish/English) and a Light/Dark mode toggle.

## Style Guidelines:

- Primary color: Soft light pink (#FFD1DC) to evoke romance and tenderness.
- Background color: Very soft white (#F8F8F8) for a clean and gentle backdrop.
- Accent color: Lavender blue (#D1E0FF) to complement the pink and add a touch of serenity.
- Text color: Soft dark gray (#333333) for readability without harshness.
- Body and headline font: 'Alegreya', serif, for its elegant, intellectual, contemporary feel.
- Use SVG icons of hearts, rings, and couples for memory game cards. SVG format maintains sharpness and detail across all devices. Use larger icons for celebratory animations
- Design a responsive layout that adapts flawlessly to mobile and desktop screens, ensuring a smooth and engaging user experience on any device.
- Add subtle and romantic animations such as confetti or floating hearts on acceptance to amplify the celebratory feel.
- Implement a dark mode with darker shades of the pastel color palette for comfortable nighttime viewing.
